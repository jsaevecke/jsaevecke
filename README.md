# Julien Saevecke

Backend / Platform Engineer working primarily with **Go**, **PostgreSQL**, and **Kubernetes**.

I build and operate backend systems across application code, databases, deployment, observability, and production troubleshooting. I am particularly interested in distributed-system correctness, reliability, and understanding how systems behave under failure.

## Current focus

- PostgreSQL concurrency, transactions, and locking
- Reliable asynchronous processing and distributed failure handling
- Go concurrency, backpressure, cancellation, and production behavior
- Kubernetes troubleshooting and production failure modes
- Infrastructure as Code with Terraform, with AWS/EKS as a planned extension
- System design for observable and recoverable services

## Engineering labs

[`go-system-labs`](https://github.com/jsaevecke/go-system-labs) — small experiments and implementations for exploring backend and systems behavior in Go.

[`k8s-system-labs`](https://github.com/jsaevecke/k8s-system-labs) — hands-on Kubernetes failure and troubleshooting labs focused on diagnosis, mitigation, recovery, and prevention. The project starts with local Kubernetes scenarios and is intended to grow into Terraform-provisioned AWS/EKS labs.

A larger reliability-focused backend project will be added here as it develops.
